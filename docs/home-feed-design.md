# Learning community Home

Home uses the EduPro graduation wordmark, a blue learning banner, a quick post
composer and rounded cards. Saved and Profile shortcuts use real account data.
Skills and Chat remain accessible through the existing navigation.

Home shows posts in newest-first order. Category chips remain compatible with
the post editor. Search combines
titles, body text, authors, categories and tags, without changing the selected
category. The header and category chips collapse when scrolling down and return
together when scrolling up. The learning banner stays in the top of the feed and
only returns when scrolling back to its original position.

Photo, Video, File and Link open the existing editor with the corresponding
picker or link form. The composer prompt and Post button open a blank editor.
The usual title, category and content requirements still apply before publishing.
The reference's network/following/poll controls are not shown because those
features have no supporting implementation in this app.

Post cards retain the existing like, comment, owner actions and bookmark
behavior. A title or attachment opens the full post. Share copies the title,
body, tags and existing link, with an explicit confirmation that it can be
pasted elsewhere; it does not invent a public post URL or publish externally.
